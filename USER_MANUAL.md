## Русская версия

Подробная инструкция: прибор, веб-интерфейс и регистрация API-ключей

Прибор на ESP32-C3 с круглым экраном 240×240 показывает самолёты поблизости на радаре и работает как набор авиационных часов с погодой. Всё настраивается через браузер телефона или компьютера.

**Что здесь есть:** подключение к Wi-Fi, радар, часы и приборы, источники данных, погода, регистрация и ключи API, резервные копии, решение проблем. Описание самой прошивки в этой инструкции не приводится.

### 1. Что понадобится

- Сам прибор с кабелем питания USB.
- Домашняя сеть Wi-Fi **2,4 ГГц**. Сеть 5 ГГц прибор не видит.
- Телефон или компьютер с браузером для настройки.
- Для части источников данных — учётные записи и ключи (см. раздел 9). Без них радар и часы работают, но часть данных может быть недоступна.

### 2. Включение и подключение к Wi-Fi

#### 2.1. Первое включение без домашней сети

1.  Включите прибор в розетку через USB.
2.  Если домашний Wi-Fi не настроен или не подключается, прибор создаёт собственную точку доступа **RADAR**.
3.  На телефоне или компьютере откройте список сетей Wi-Fi и подключитесь к **RADAR**. Пароль точки указан на главной странице настроек, по умолчанию это **11223344**.
4.  Откройте в браузере адрес **http://192.168.4.1**.
5.  Выберите свою домашнюю сеть из списка («Поиск сетей») или введите её имя вручную, введите пароль и нажмите «Сохранить».
6.  Прибор перезагрузится и подключится к домашней сети.

Если система сообщает, что в сети **RADAR** нет интернета, выберите «остаться подключённым». Сам прибор интернет не требует, его настройки открываются по локальному адресу.

#### 2.2. Стартовый экран

| Ситуация                    | Что показывает прибор                                                                                                                                                                                                                               |
|-----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Домашний Wi-Fi подключён    | Надпись «ВАША СЕТЬ» / “YOUR NETWORK”, имя сети (SSID), IP-адрес и адрес веб-интерфейса вида `http://192.168.x.x`. Экран показывается 10 секунд, затем открывается радар или часы — в зависимости от настроек.                                       |
| Домашний Wi-Fi не подключён | Надписи «ДОМАШНИЙ WI-FI НЕ ПОДКЛЮЧЕН» / «ПОДКЛЮЧИТЕСЬ К RADAR», имя сети **RADAR** и адрес `HTTP://192.168.4.1`. Экран держится до 5 минут или до нажатия кнопки, затем прибор переходит к часам. Точка **RADAR** и веб-сервер продолжают работать. |

Адрес в домашней сети может измениться после перезагрузки роутера. Актуальный адрес всегда виден на стартовом экране и вверху главной страницы.

#### 2.3. Аварийная точка RADAR

Если домашняя сеть подключена, точка **RADAR** работает 10 минут после запуска и затем отключается. Так она не открывает доступ к прибору постоянно. Если домашней сети нет, точка остаётся включённой, пока вы не подключитесь к ней или не настроите Wi-Fi.

### 3. Кнопка прибора

| Действие                 | Результат                                                                                                           |
|--------------------------|---------------------------------------------------------------------------------------------------------------------|
| Короткое нажатие         | На радаре — следующий масштаб. В часах — следующий стиль. В режиме циклического показа масштабы переключаются сами. |
| Удержание около 3 секунд | Переключение между радаром и часами.                                                                                |

Длинное нажатие распознаётся по времени удержания в момент отпускания, поэтому работает даже тогда, когда прибор занят запросом данных.

### 4. Главная страница настроек

Откройте адрес прибора в браузере. Вверху страницы показаны режим сети и IP-адрес, есть переключатель языка RU / EN.

| Блок                      | Что настраивается                                                                                      |
|---------------------------|--------------------------------------------------------------------------------------------------------|
| Аварийная точка RADAR     | Имя точки, пароль, адрес и срок работы (10 минут при подключённой домашней сети).                      |
| Wi-Fi                     | Имя домашней сети и пароль. Поле пароля при сохранении можно оставить пустым, тогда останется текущий. |
| Радар: столица и аэропорт | Список из 189 аэропортов (см. ниже). Выбор заполняет город, координаты и код аэропорта.                |
| Название города на экране | До 24 символов, выводится на радаре и в часах.                                                         |
| Координаты центра         | Широта и долгота. Можно ввести вручную, если нужной точки нет в списке.                                |
| Единицы масштаба          | Километры или мили.                                                                                    |
| Свой масштаб              | Любое значение от 0,1 до 1000 км (или миль). Пусто — выбрать масштаб из списка.                        |
| Масштаб при запуске       | Какой масштаб показывать после включения.                                                              |

#### Список аэропортов

Список содержит 189 аэропортов. Сначала идут 125 российских аэропортов по алфавиту названий городов (номера 1–125), затем 64 иностранных — 4 кыргызских и 60 мировых хабов — тоже по алфавиту (номера 126–189). Номера видны в списке. Полный список с кодами IATA и ICAO и координатами можно найти в файле **AIRPORTS_LIST**, который поставляется с прошивкой.

Выбранный аэропорт задаёт центр радара и метеостанцию NOAA METAR. Для погоды NOAA нужен именно аэропорт из списка, а не произвольные координаты.

### 5. Радар: масштабы, самолёты, подписи, поиск

#### 5.1. Масштабы

Доступные масштабы: **6, 10, 20, 50, 100, 200, 400 и 1000 км**. Короткое нажатие кнопки переключает их по кругу. Ручной выбор кнопкой сохраняется как масштаб по умолчанию и после выключения питания.

На странице **«Масштабы радара»** можно отметить, какие масштабы участвуют в переключении кнопкой, и задать время показа каждого при циклическом режиме.

#### 5.2. Как выглядит радар

- **Центр** — выбранный город или аэропорт.
- **Самолёты** — значки, повёрнутые по курсу. Вид значка выбирается на странице «Источники данных»: **жёлтый силуэт самолёта** или **красный треугольник**. У обоих есть фиолетовая линия направления движения. Размер значка — маленький, средний или крупный.
- **Выбранный самолёт** — обведён оранжевым пунктиром. Выделить его можно из списка «Самолёты поблизости».
- **Красные точки на краю** — самолёты дальше текущего масштаба. Нажмите кнопку или выберите масштаб побольше, чтобы их увидеть.
- **Следы** — линия, по которой самолёт летел. Включается на странице источников, длину истории можно задать.
- **Карта** — границы, реки и озёра под радаром. Включается отдельным переключателем.

![Радар](docs/radar.svg)

Радар. Схема экрана: сверху название города, внизу трёхбуквенный код аэропорта и число самолётов. Самолёты — силуэты, синим показана карта. У выбранного самолёта оранжевый пунктир и подписи высоты и скорости. Красные точки — самолёты за пределами масштаба.

#### 5.3. Подписи самолётов

На странице источников можно включить подписи: позывной, высота, скорость, курс, расстояние от центра, ICAO. Единицы подписей — метрические (км, км/ч) или авиационные (FL, kt, nm). Размер шрифта подписей выбирается в блоке «Подписи рядом с самолётом»: мелкий, средний или крупный.

#### 5.4. Автопоиск самолётов

Если включён автопоиск и на экране нет ни одного самолёта в течение заданного времени, радар переходит к следующему масштабу и ищет дальше, вплоть до 400 км. Когда самолёт найден, радар остаётся на этом масштабе. Автопоиск не работает одновременно с циклическим показом масштабов.

#### 5.5. Поиск самолёта по ICAO

Если функция включена, можно найти конкретный борт по его ICAO-коду (шестизначный код). Если борт попадает в зону радара, он будет выделен.

#### 5.6. Автомасштаб и случайный аэропорт

**Автомасштаб по числу самолётов.** Настраивается на странице «Масштабы». Если на экране самолётов больше, чем в поле «Максимум самолётов на экране» (по умолчанию 15), масштаб уменьшается на один шаг. Если самолётов нет минуту, масштаб увеличивается на шаг, но не больше 400 км. Между шагами проходит 15 секунд. Пока функция включена, она заменяет автопоиск из раздела 5.4. Галочкой её можно выключить: тогда снова работает автопоиск.

**Случайный аэропорт.** Раз в заданное число минут (по умолчанию 10) центр радара и погода переходят на случайный аэропорт из списка, масштаб становится 50 км. Это временно: аэропорт, выбранный на главной странице, не меняется, и после перезагрузки снова включается он. Функцию можно выключить на той же странице. Если кнопкой листаются масштабы радара, после последнего масштаба появляется пункт аэропорта: на домашнем аэропорте — «Случайный аэропорт», на случайном — «Домашний аэропорт». Пункт подтверждается паузой, как «АВТО». «Домашний аэропорт» возвращает аэропорт с главной страницы с прежним масштабом и останавливает случайную смену, пока не выбран пункт «Случайный аэропорт» или не перезагружен прибор.

#### 5.7. Отслеживание выбранного самолёта

Включается галкой на странице «Самолёты» (/aircraft) под выбором самолёта. Пока галка включена и самолёт выбран, на радаре нет других самолётов, их подписей и следов. Если выбранный самолёт уходит с экрана, масштаб увеличивается шагами, пока самолёт снова не появится. Когда он пропадает совсем на масштабе 1000 км, отслеживание выключается само. Пока оно работает, автопоиск, автомасштаб по числу самолётов, листание по кругу и случайный аэропорт не меняют масштаб и аэропорт.

#### 5.8. Коды ответчика (squawk)

Прибор читает код ответчика самолёта из источников данных, если источник его передаёт: OpenSky, adsb.fi, adsb.lol, adsb.one, airplanes.live и FR24. Код состоит из четырёх цифр.

Коды **7500**, **7600** и **7700** выделяются на радаре залитым красным кружком, над которым написан сам код:

- **7500** — угон самолёта (захват воздушного судна).
- **7600** — отказ радиосвязи.
- **7700** — общая аварийная ситуация.

Остальные коды на радаре не выделяются. Если источник код не передаёт, кружок не появится. Не путать с часами «Транспондер»: там выводится время ЧЧММ в виде кода, а не код самолёта.

#### 5.9. Значения по умолчанию

При первом запуске, а также после сброса настроек прибор использует такие значения:

- Центр радара и погода: аэропорт Храброво, Калининград (KGD).
- Масштаб радара: 200 км.
- Случайный аэропорт: выключен. Его можно включить на странице масштабов.
- Источники самолётов: adsb.fi и adsb.lol включены; OpenSky, airplanes.live, adsb.one и Flightradar24 выключены.
- Погода: NOAA METAR по выбранному аэропорту.
- Без интернета часы открываются в стиле «авиагоризонт».

Когда вы выберете другой аэропорт, центр радара и погода METAR будут брать его. Сохранённые вами настройки на приборе не меняются.

#### 5.10. Ночной режим экрана

Ночью экран гаснет, днём включается снова. На странице «Часы» включите ночной режим отдельно для часов и для радара: поставьте галку «Ночью выключать экран в часах», «Ночью выключать экран в радаре» или обе. Время начала ночи и дня задаётся там же, например с 22:00 до 07:00. Время берётся из синхронизации (NTP или браузера). Без синхронизации времени экран не гаснет. Подсветка модуля продолжает гореть: регулировать её яркость этот модуль не позволяет.

Ночью нажатие кнопки BOOT включает экран на 15 секунд, затем он снова гаснет. Нажатие в это время не меняет стиль часов и масштаб радара.

### 6. Самолёты поблизости

Страница «Самолёты поблизости» показывает список самолётов в текущем радиусе радара, отсортированный по расстоянию. Список обновляется примерно каждые 10 секунд. Для каждого самолёта видны позывной, ICAO, источник данных, расстояние, высота, скорость, курс и вертикальная скорость — если источник их передаёт.

Нажмите на самолёт, чтобы выделить его на радаре оранжевым пунктиром. Выделение сохраняется, пока вы его не снимете или самолёт не пропадёт из зоны радара.

### 7. Источники данных

Страница «Источники данных» управляет тем, откуда берутся самолёты, и показывает их статус.

#### 7.1. Источники самолётов

| Источник        | Ключ                                       | Интервал по умолчанию и ограничения                                                                              |
|-----------------|--------------------------------------------|------------------------------------------------------------------------------------------------------------------|
| OpenSky Network | Нужны Client ID и Client Secret (раздел 9) | 22 секунды; ручной ввод от 10 секунд. Для бесплатного доступа рекомендуется не чаще одного запроса в 23 секунды. |
| adsb.fi         | Не нужен                                   | Интервал по умолчанию, см. страницу источников.                                                                  |
| airplanes.live  | Не нужен                                   | Интервал по умолчанию, см. страницу источников.                                                                  |
| adsb.lol        | Не нужен                                   | Интервал по умолчанию, см. страницу источников.                                                                  |
| adsb.one        | Не нужен                                   | Интервал по умолчанию, см. страницу источников.                                                                  |
| Flightradar24   | Нужен API-токен (платная подписка на API)  | Минимальный интервал 30 секунд. Запросы расходуют API-кредиты.                                                   |

Каждый источник можно включить или выключить отдельно. Интервал задаётся в поле рядом, в допустимом интерфейсом диапазоне.

Интервалы и лимиты сервисов могут меняться. Если источник начал выдавать ошибки, проверьте его статус на странице источников и условия на официальном сайте сервиса.

#### 7.2. Статус источников

Названия источников показаны разными цветами, статусы — белым текстом. Цвет лишь помогает различать сервисы и не означает состояние подключения.

#### 7.3. Подробная диагностика

Блок «Подробная диагностика источников» обновляется каждые 5 секунд. Для каждого **включённого** источника показано: время последнего успешного ответа, время последней попытки, число принятых бортов, самый свежий возраст позиции (если источник его передаёт), последний HTTP-код и текст ошибки. Выключенные источники в диагностике не выводятся. Если ни один не включён, блок показывает пометку об этом. Время отсчитывается от включения прибора и сбрасывается при перезагрузке.

#### 7.4. Карта, следы, значок

- **Карта под радаром** — включается переключателем «Карта».
- **Следы самолётов** — включаются переключателем «Следы»; по умолчанию длина истории 120 секунд.
- **Значок самолёта** — блок «Значок самолёта»: вид (силуэт или треугольник) и размер.

### 8. Погода

Погода нужна для стилей часов с погодой (ветер, метео, метеостанция) и для строки погоды на экране. Настройка находится в разделе «Источники» → «Настройка источников погоды».

| Провайдер      | Ключ     | Что важно знать                                                                                                          |
|----------------|----------|--------------------------------------------------------------------------------------------------------------------------|
| Open-Meteo     | Не нужен | Работает сразу. Температура, влажность, осадки, облачность, ветер, давление. Выбран по умолчанию.                        |
| OpenWeatherMap | Нужен    | Обновление каждые 15 минут. Бесплатный тариф, см. раздел 9.                                                              |
| WeatherStack   | Нужен    | Бесплатно 100 запросов в месяц, поэтому обновление раз в 8 часов.                                                        |
| NOAA METAR     | Не нужен | Погода выбранного аэропорта по данным METAR. Нужен аэропорт из списка на главной странице, а не произвольные координаты. |

**Порядок настройки:**

1.  Откройте «Источники» → «Настройка источников погоды».
2.  В поле «Использовать для часов» выберите провайдера.
3.  Если провайдер требует ключ, вставьте его в поле. Если ключ уже сохранён, поле пустое — оставьте его пустым, чтобы не менять.
4.  Выберите единицы: температура °C или °F, давление гПа или мм рт. ст.
5.  Нажмите «Сохранить». Новый провайдер запрашивается сразу.

Если погода не появляется, блок «Погода для часов» на странице источников покажет причину: нет Wi-Fi, нет ключа, ошибка провайдера или связи.

### 9. Регистрация и API-ключи

Ниже — пошаговая регистрация для сервисов, которым нужны учётные данные. Адреса и названия разделов на сайтах со временем меняются, поэтому при расхождении ориентируйтесь на официальную справку сервиса. Не отправляйте ключи на сторонние сайты и не публикуйте их.

#### 9.1. OpenSky Network (бесплатно, OAuth2)

1.  Откройте официальный сайт **opensky-network.org** и зарегистрируйтесь или войдите в аккаунт.
2.  На странице аккаунта найдите раздел **API Clients** и создайте новый API-клиент.
3.  Скачайте выданный файл **credentials.json**. Он содержит поля `clientId` и `clientSecret`.
4.  На приборе откройте **«Источники данных» → OpenSky → «Загрузить credentials.json»**, выберите файл и подтвердите.
5.  Если не хотите загружать файл, введите Client ID вручную, а Client Secret — в защищённое поле на странице источников.
6.  Проверьте, что флажок **«Использовать OpenSky»** установлен, и нажмите «Сохранить».

OpenSky использует OAuth2 Client Credentials. Логин и пароль от сайта для прибора не подходят — нужны именно Client ID и Client Secret API-клиента. Официальная документация по авторизации: openskynetwork.github.io/opensky-api/rest.html

#### 9.2. Flightradar24 API (платный)

Для этого источника нужна **отдельная подписка именно на API** с API-кредитами. Обычная подписка на сайт Flightradar24 доступа к API не даёт.

1.  Откройте портал Flightradar24 API (fr24api.flightradar24.com) и создайте аккаунт или войдите.
2.  Перейдите в раздел **Subscription & credits** и выберите и активируйте API-план.
3.  Откройте **Key management** и нажмите **Create token**. Сохраните токен сразу в надёжном месте — значение может больше не показываться.
4.  На приборе откройте «Источники данных» → Flightradar24, вставьте токен в поле **API token** и нажмите «Сохранить».

Документация: fr24api.flightradar24.com/docs/getting-started и fr24api.flightradar24.com/docs/authentication

#### 9.3. OpenWeatherMap (погода, бесплатный ключ)

1.  Откройте сайт **openweathermap.org** и зарегистрируйтесь.
2.  Подтвердите адрес электронной почты: письмо приходит на почту, которую вы указали.
3.  В личном кабинете откройте раздел **API keys** и скопируйте ключ. Ключ может появиться не сразу, иногда через некоторое время после регистрации.
4.  На приборе откройте «Источники» → «Настройка источников погоды», выберите OpenWeatherMap и вставьте ключ в поле. Нажмите «Сохранить».

По описанию в этой инструкции бесплатный тариф не требует карты, но условия могут меняться — проверьте их на сайте перед регистрацией.

#### 9.4. WeatherStack (погода, бесплатный ключ)

1.  Откройте сайт **weatherstack.com** и зарегистрируйтесь на бесплатный тариф.
2.  Скопируйте **Access Key** из личного кабинета.
3.  На приборе откройте «Настройка источников погоды», выберите WeatherStack и вставьте ключ. Нажмите «Сохранить».

Бесплатный тариф ограничен количеством запросов в месяц, поэтому прибор обновляет погоду раз в 8 часов.

#### 9.5. Источники без ключей

Для этих источников регистрация не нужна: **Open-Meteo**, **NOAA METAR** (aviationweather.gov), **adsb.fi**, **airplanes.live**, **adsb.lol**, **adsb.one**. Соблюдайте лимиты и условия использования каждого сервиса.

#### 9.6. Где хранятся ключи

- Ключи и токены хранятся в памяти прибора.
- В файл резервной копии настроек ключи **не попадают**. После восстановления из файла проверьте их на странице погоды и на странице источников.
- Файл **credentials.json** от OpenSky — секретный. Не публикуйте его и не отправляйте посторонним.

Стили погоды (ветер, метео, метеостанция) работают только при подключённом Wi-Fi и выбранном провайдере погоды.

Можно задать автоматическое переключение стилей и время показа каждого. Отдельно включаются симуляция движения авиагоризонта и вращение шкалы гирокомпаса. Изменения нужно сохранить.

В настройках также выбирается режим после включения — радар или часы.

### 11. Время и синхронизация

Часы берут время из интернета по протоколу NTP. На странице «Часы» доступны:

- кнопка **«Синхронизировать с браузером»** — передаёт прибору текущее время и часовой пояс устройства, с которого открыта страница. Работает и при прямом подключении к точке **RADAR**;
- ручной часовой пояс относительно UTC;
- адрес сервера NTP, по умолчанию `pool.ntp.org`; можно вернуть значение по умолчанию кнопкой сброса;
- статус синхронизации.

После включения часы сначала показывают резервное время **11:11, 1 января 2026 года** в выбранном поясе. Оно идёт как обычные часы, пока не придёт подтверждённое время из NTP или не будет выполнена синхронизация с браузером. После этого дата и время исправляются автоматически.

Если синхронизация не проходит, проверьте подключение к домашней сети и доступ к NTP-серверам. В режиме точки **RADAR** без интернета NTP может быть недоступен — тогда используйте кнопку «Синхронизировать с браузером».

| Статический IP | Нужен, если адрес должен быть постоянным. Укажите IP устройства, шлюз роутера, маску подсети и DNS 1 и DNS 2. |

Перед сохранением статического адреса убедитесь, что он входит в подсеть роутера и не занят другим устройством. Если адрес выбран неверно, подключитесь к точке **RADAR**, откройте `http://192.168.4.1` и верните DHCP.

### 13. Конфигурация: резервная копия, восстановление, сброс

Страница «Конфигурация устройства» содержит:

- **Загрузить конфигурацию** — выберите ранее сохранённый файл. Текущие настройки будут заменены.
- **Сброс настроек** — удаляет сохранённые настройки Wi-Fi, радара, часов и источников. Выполняется только после подтверждения.

В файл резервной копии не входят пароль Wi-Fi, Client ID и Client Secret OpenSky, токены API и ключи погоды. После восстановления их нужно ввести заново или проверить. Файл с секретами OpenSky (credentials.json) храните отдельно.

### 14. Безопасность

- Пароль точки **RADAR** по умолчанию (**11223344**) общеизвестен. Точка доступна только до подключения домашней сети и 10 минут после запуска, если сеть уже подключена, поэтому не оставляйте прибор с открытой точкой там, где к ней могут подключиться посторонние.
- Не публикуйте Client Secret, токены и ключи API в открытых репозиториях, скриншотах и сообщениях. Если секрет попал в открытый доступ, отзовите его на сайте сервиса и создайте новый.
- Не открывайте адрес прибора из интернета: страницы настроек рассчитаны на домашнюю сеть.
- Для безопасного переноса прибора сохраните конфигурацию, а ключи введите заново на новом месте.

### 1. What you need

- The device with a USB power cable.
- A home Wi-Fi network on **2.4 GHz**. The device cannot see 5 GHz networks.
- A phone or computer with a browser for setup.
- For some data sources: accounts and keys (see section 9). Without them the radar and clocks still work, but some data may be unavailable.

### 2. Power on and Wi-Fi connection

#### 2.1. First power-on without a home network

1.  Plug the device into a USB power source.
2.  If the home Wi-Fi is not set up or does not connect, the device creates its own access point **RADAR**.
3.  On your phone or computer, open the Wi-Fi list and connect to **RADAR**. The access point password is shown on the main settings page; by default it is **11223344**.
4.  Open **http://192.168.4.1** in a browser.
5.  Choose your home network from the list ("Scan networks") or type its name, enter the password and press "Save".
6.  The device restarts and connects to your home network.

If your system says the **RADAR** network has no internet access, choose to stay connected. The device does not need internet access to serve its settings pages on the local address.

#### 2.2. Startup screen

| Situation                   | What the device shows                                                                                                                                                                                                                                                                              |
|-----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Home Wi-Fi is connected     | The text "YOUR NETWORK", the network name (SSID), the IP address and the web-interface address such as `http://192.168.x.x`. The screen stays for 10 seconds, then the radar or clock opens, depending on settings.                                                                                |
| Home Wi-Fi is not connected | The texts "HOME WI-FI NOT CONNECTED" / "CONNECT TO RADAR", the **RADAR** network name and the address `HTTP://192.168.4.1`. The screen stays for up to 5 minutes or until you press the button, then the device switches to the clock. The **RADAR** access point and the web server keep working. |

The address on the home network can change after a router restart. The current address is always shown on the startup screen and at the top of the main page.

#### 2.3. Emergency RADAR access point

If the home network is connected, the **RADAR** access point works for 10 minutes after startup and then turns off. This way it does not stay open to others. If there is no home network, the access point stays on until you connect to it or set up Wi-Fi.

### 3. Device button

| Action                   | Result                                                                                                          |
|--------------------------|-----------------------------------------------------------------------------------------------------------------|
| Short press              | On the radar: next scale. In the clocks: next style. In automatic cycling mode the scales change by themselves. |
| Hold for about 3 seconds | Switches between the radar and the clock.                                                                       |

A long press is recognised by how long the button is held when released, so it works even while the device is busy with a data request.

#### Airport list

The list contains 189 airports. First come 125 Russian airports sorted alphabetically by city name (numbers 1–125), then 64 foreign airports — 4 Kyrgyz airports and 60 world hubs — also sorted alphabetically (numbers 126–189). The numbers are shown in the list. The full list with IATA and ICAO codes and coordinates is in the **AIRPORTS_LIST** file supplied with the firmware.

The selected airport sets the radar centre and the NOAA METAR weather station. NOAA weather needs an airport from the list, not arbitrary coordinates.

### 5. Radar: scales, aircraft, labels, search

#### 5.1. Scales

Available scales: **6, 10, 20, 50, 100, 200, 400 and 1000 km**. A short press of the button cycles through them. A scale you select with the button is saved as the default and restored after power-off.

On the **Radar scales** page you can mark which scales take part in button switching and set the display time for each scale in cycling mode.

#### 5.2. How the radar looks

- **Centre** — the chosen city or airport.
- **Aircraft** — icons rotated to the heading. The icon type is chosen on the Data sources page: **yellow aircraft silhouette** or **red triangle**. Both have a purple heading line. Size: small, medium or large.
- **Selected aircraft** — outlined with an orange dashed square. You can select it from the "Nearby aircraft" list.
- **Red dots at the edge** — aircraft beyond the current scale. Press the button or choose a larger scale to see them.
- **Trails** — the line the aircraft has flown. Enabled on the sources page; you can set the history length.
- **Map** — borders, rivers and lakes under the radar. Enabled with its own switch.

![Radar](docs/radar.svg)

Radar. Schematic: city name at the top, three-letter airport code and aircraft count at the bottom. Aircraft are silhouettes, the map is blue. The selected aircraft has an orange dashed outline and altitude and speed labels. Red dots mark aircraft beyond the scale.

#### 5.3. Aircraft labels

On the sources page you can enable labels: callsign, altitude, speed, heading, distance from the centre and ICAO. Units are metric (km, km/h) or aviation (FL, kt, nm). The label font size is set in the "Labels next to aircraft" block: small, medium or large.

#### 5.4. Automatic aircraft search

If automatic search is enabled and no aircraft is visible for the set time, the radar moves to the next scale and keeps searching up to 400 km. When an aircraft is found, the radar stays on that scale. Automatic search does not work together with cycling through scales.

#### 5.5. Search by ICAO

If enabled, you can find a specific aircraft by its six-character ICAO code. If the aircraft enters the radar area, it is highlighted.

#### 5.6. Auto-scale and random airport

**Auto-scale by aircraft count.** Set on the "Scales" page. If more aircraft are on screen than the "Maximum aircraft on screen" field allows (default 15), the scale decreases by one step. If there are no aircraft for one minute, the scale increases by one step, up to 400 km. There are 15 seconds between steps. While this is on, it replaces the auto-search from section 5.4. Untick it to turn it off: the auto-search then works again.

**Random airport.** Every set number of minutes (default 10), the radar centre and weather switch to a random airport from the list, and the scale becomes 50 km. This is temporary: the airport chosen on the main page does not change, and it is used again after a restart. The feature can be turned off on the same page. When the button pages through the radar scales, after the last scale an airport item appears: on the home airport it is "Random airport", on a random airport it is "Home airport". It is confirmed with a pause, like "AUTO". "Home airport" returns to the airport from the main page with the previous scale and stops random switching until the "Random airport" item is chosen or the device is restarted.

#### 5.7. Tracking the selected aircraft

It is turned on by the checkbox on the Aircraft page (/aircraft) under the aircraft selection. While it is on and an aircraft is selected, the radar shows no other aircraft, labels or trails. If the selected aircraft leaves the screen, the scale increases in steps until it appears again. When it is gone completely at the 1000 km scale, tracking switches itself off. While tracking works, auto-search, auto-scale by aircraft count, the scale loop and the random airport do not change the scale or airport.

#### 5.8. Transponder codes (squawk)

The device reads an aircraft's transponder code (squawk) from the data sources that provide it: OpenSky, adsb.fi, adsb.lol, adsb.one, airplanes.live and FR24. The code has four digits.

The codes **7500**, **7600** and **7700** are shown on the radar as a filled red circle with the code written above it:

- **7500** — hijacking (unlawful interference with the aircraft).
- **7600** — radio communication failure.
- **7700** — general emergency.

Other codes are not highlighted. If a source does not provide the code, no circle appears. Do not confuse this with the "Transponder" clock: there the time HHMM is shown as a code, not the aircraft's code.

#### 5.9. Default values

On first start, and after a settings reset, the device uses these values:

- Radar centre and weather: Khrabrovo airport, Kaliningrad (KGD).
- Radar scale: 200 km.
- Random airport: off. You can turn it on on the scales page.
- Aircraft sources: adsb.fi and adsb.lol enabled; OpenSky, airplanes.live, adsb.one and Flightradar24 disabled.
- Weather: NOAA METAR for the selected airport.
- Without internet, the clock opens in the artificial horizon style.

When you select another airport, the radar centre and METAR weather use it. Settings you have saved stay unchanged on the device.

#### 5.10. Night screen mode

At night the screen turns off, and in the day it turns on again. On the Clock page turn on night mode separately for clock and radar: tick "Turn screen off at night in clock mode", "Turn screen off at night in radar mode", or both. The night and day start times are set there too, for example from 22:00 to 07:00. The time comes from synchronization (NTP or browser). Without time sync the screen stays on. The module backlight keeps shining, because this module does not allow dimming it.

At night a press of the BOOT button turns the screen on for 15 seconds, then it turns off again. This press does not change the clock style or the radar scale.

### 6. Nearby aircraft

The "Nearby aircraft" page lists aircraft within the current radar range, sorted by distance. The list refreshes about every 10 seconds. For each aircraft you see the callsign, ICAO, data source, distance, altitude, speed, heading and vertical speed when the source provides them.

Press an aircraft to highlight it on the radar with an orange dashed outline. The highlight stays until you clear it or the aircraft leaves the radar area.

### 7. Data sources

The "Data sources" page controls where the aircraft data comes from and shows their status.

#### 7.1. Aircraft sources

| Source          | Key                                            | Default interval and limits                                                                                          |
|-----------------|------------------------------------------------|----------------------------------------------------------------------------------------------------------------------|
| OpenSky Network | Client ID and Client Secret needed (section 9) | 22 seconds; manual entry from 10 seconds. For free access, no more than one request every 23 seconds is recommended. |
| adsb.fi         | Not needed                                     | Default interval, see the sources page.                                                                              |
| airplanes.live  | Not needed                                     | Default interval, see the sources page.                                                                              |
| adsb.lol        | Not needed                                     | Default interval, see the sources page.                                                                              |
| adsb.one        | Not needed                                     | Default interval, see the sources page.                                                                              |
| Flightradar24   | API token needed (paid API subscription)       | Minimum interval 30 seconds. Requests use API credits.                                                               |

Each source can be enabled or disabled separately. The interval is set in the field next to it, within the range allowed by the interface.

Service intervals and limits may change. If a source starts returning errors, check its status on the sources page and the terms on the service's official website.

#### 7.2. Source status

Source names are shown in different colours and status text is white. The colour only helps tell the services apart and does not mean the connection state.

#### 7.3. Detailed diagnostics

The "Detailed source diagnostics" block refreshes every 5 seconds. For each **enabled** source it shows: time of the last successful response, time of the last attempt, number of aircraft received, freshest position age (if the source provides it), last HTTP code and error text. Disabled sources are not shown. If none is enabled, the block says so. Times count from power-on and reset on restart.

#### 7.4. Map, trails, icon

- **Map under the radar** — enabled with the "Map" switch.
- **Aircraft trails** — enabled with the "Trails" switch; the default history is 120 seconds.
- **Aircraft icon** — the "Aircraft marker" block: type (silhouette or triangle) and size.

### 8. Weather

Weather is used by the clock styles with weather (wind, METAR, weather station) and by the weather line on the screen. The settings are on the "Sources" page → "Weather provider settings".

| Provider       | Key        | What to know                                                                                                                     |
|----------------|------------|----------------------------------------------------------------------------------------------------------------------------------|
| Open-Meteo     | Not needed | Works immediately. Temperature, humidity, precipitation, cloud cover, wind, pressure. Default choice.                            |
| OpenWeatherMap | Needed     | Updates every 15 minutes. Free plan, see section 9.                                                                              |
| WeatherStack   | Needed     | 100 free requests per month, so updates happen every 8 hours.                                                                    |
| NOAA METAR     | Not needed | Weather of the selected airport from METAR data. An airport from the list on the main page is needed, not arbitrary coordinates. |

**Setup:**

1.  Open "Sources" → "Weather provider settings".
2.  In the "Use for clocks" field choose the provider.
3.  If the provider needs a key, paste it into the field. If a key is already saved, the field is empty — leave it empty to keep it.
4.  Choose units: temperature °C or °F, pressure hPa or mmHg.
5.  Press "Save". The new provider is requested at once.

If no weather appears, the "Weather for clocks" block on the sources page shows the reason: no Wi-Fi, no key, a provider error or a connection error.

### 9. Registration and API keys

Below are step-by-step instructions for services that need credentials. Site addresses and section names change over time, so if something differs, follow the service's official help. Do not send keys to third-party sites and do not publish them.

#### 9.1. OpenSky Network (free, OAuth2)

1.  Open the official site **opensky-network.org** and sign up or log in.
2.  On your account page find the **API Clients** section and create a new API client.
3.  Download the issued file **credentials.json**. It contains the fields `clientId` and `clientSecret`.
4.  On the device open **Data sources → OpenSky → "Upload credentials.json"**, choose the file and confirm.
5.  If you do not want to upload the file, type the Client ID manually and enter the Client Secret in the protected field on the sources page.
6.  Make sure the **"Use OpenSky"** checkbox is ticked and press "Save".

OpenSky uses OAuth2 Client Credentials. Your website login and password do not work for the device — you need the Client ID and Client Secret of the API client. Official authentication documentation: openskynetwork.github.io/opensky-api/rest.html

#### 9.2. Flightradar24 API (paid)

This source needs a **separate API subscription** with API credits. A regular Flightradar24 website subscription does not give API access.

1.  Open the Flightradar24 API portal (fr24api.flightradar24.com), sign up or log in.
2.  Go to **Subscription & credits** and choose and activate an API plan.
3.  Open **Key management** and press **Create token**. Save the token somewhere safe immediately — the value may not be shown again.
4.  On the device open Data sources → Flightradar24, paste the token into the **API token** field and press "Save".

Documentation: fr24api.flightradar24.com/docs/getting-started and fr24api.flightradar24.com/docs/authentication

#### 9.3. OpenWeatherMap (weather, free key)

1.  Open **openweathermap.org** and sign up.
2.  Confirm your email address: the message is sent to the address you entered.
3.  In your account open the **API keys** section and copy the key. The key may appear with a delay after registration.
4.  On the device open "Sources" → "Weather provider settings", choose OpenWeatherMap and paste the key. Press "Save".

As described in this manual, the free plan does not require a card, but terms can change — check them on the site before signing up.

#### 9.4. WeatherStack (weather, free key)

1.  Open **weatherstack.com** and sign up for the free plan.
2.  Copy the **Access Key** from your account dashboard.
3.  On the device open "Weather provider settings", choose WeatherStack and paste the key. Press "Save".

The free plan is limited in requests per month, so the device updates the weather every 8 hours.

#### 9.5. Sources without keys

No registration is needed for: **Open-Meteo**, **NOAA METAR** (aviationweather.gov), **adsb.fi**, **airplanes.live**, **adsb.lol**, **adsb.one**. Follow the limits and terms of each service.

#### 9.6. Where keys are stored

- Keys and tokens are stored in the device memory.
- Keys are **not** included in the settings backup file. After restoring from a file, check them on the weather page and the sources page.
- The OpenSky **credentials.json** file is secret. Do not publish it or send it to anyone.

### 10. Clocks and instruments

#### 10.1. Instruments

- **Altimeter** — drum-style altitude digits.
- **Gyrocompass** — a compass card making one turn every 60 seconds. Rotation can be turned off.
- **Chronograph** — cockpit clock with small dials.
- **ILS / glideslope** — deviation needles for course and glide path. Motion can be turned off.
- **Transponder** — time shown as a squawk code.
- **TERRAIN** — terrain profile and the "terrain close" warning. Motion can be turned off.

#### 10.2. Weather and station

- **Minimal** — ring with seconds.
- **Radar** — second hand.

Weather styles (wind, METAR, weather station) work only with Wi-Fi connected and a weather provider selected.

#### 10.4. Automatic switching and simulation

You can set automatic style switching and the display time for each style. Smooth attitude motion and gyrocompass rotation can be enabled separately. Save the changes.

### 11. Time and synchronization

The clock takes the time from the internet via NTP. The "Clock settings" page provides:

- the **"Sync with browser"** button — sends the device the current time and time zone of the phone or computer that has the page open. It also works when you are connected directly to the **RADAR** access point;
- a manual time zone relative to UTC;
- the NTP server address, by default `pool.ntp.org`; the reset button brings back the default;
- the time sync status.

After power-on the clock first shows a fallback time of **11:11, 1 January 2026** in the selected time zone. It runs like a normal clock until confirmed NTP time arrives or you press "Sync with browser". After that the date and time are corrected automatically.

If sync fails, check the home network connection and access to NTP servers. In **RADAR** access point mode without internet, NTP may be unavailable — use the "Sync with browser" button instead.

### 12. Network and IP address

The "Network and IP address" page is at the bottom of the "Device configuration" page.

| Mode      | When to use                                                                                               |
|-----------|-----------------------------------------------------------------------------------------------------------|
| DHCP      | The usual choice: the router assigns the address.                                                         |
| Static IP | Use it if the address must stay fixed. Enter the device IP, router gateway, subnet mask, DNS 1 and DNS 2. |

Before saving a static address make sure it is in the router's subnet and not used by another device. If the address is wrong, connect to **RADAR**, open `http://192.168.4.1` and switch back to DHCP.

### 13. Configuration: backup, restore, reset

The "Device configuration" page contains:

- **Save configuration** — downloads a JSON file with the current settings.
- **Load configuration** — choose a previously saved file. Current settings are replaced.
- **Reset settings** — deletes the saved Wi-Fi, radar, clock and source settings. Only after confirmation.
- **Device information** — version, memory, network status.

The backup file does not contain the Wi-Fi password, OpenSky Client ID and Client Secret, API tokens or weather keys. After restoring, enter or check them again. Keep the OpenSky credentials.json file separately.

### 14. Security

- The default password of the **RADAR** access point (**11223344**) is publicly known. The access point is available only until the home network connects and for 10 minutes after startup if the network is connected, so do not leave the device with an open access point where strangers can connect.
- Do not publish the Client Secret, tokens and API keys in public repositories, screenshots or messages. If a secret becomes public, revoke it on the service's website and create a new one.
- Do not expose the device address to the internet: the settings pages are designed for the home network.
- When moving the device, save the configuration and enter the keys again at the new place.

### 15. If something does not work

| Symptom                             | What to check                                                                                                                                                                         |
|-------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| The web interface does not open     | Phone and device on the same network; the address starts with `http://`, not `https://`; the current IP from the startup screen; without a home network — the **RADAR** access point. |

| The button behaves strangely        | Short and long presses differ by hold time. To switch between radar and clock, hold for about 3 seconds.                                                                              |
| Need to start over                  | "Device configuration" → "Reset settings" and confirm. Then set up Wi-Fi again.                                                                                                       |

If the problem remains, save the configuration and write to the channel or contact listed below.

### 16. Quick start (English)

1.  Power the device via USB. If home Wi-Fi is unavailable, connect to the **RADAR** network (default password 11223344) and open `http://192.168.4.1`.
2.  Choose your home Wi-Fi network, enter its password and save. The device restarts and connects.
3.  Short press: next radar scale or next clock style. Hold about 3 seconds: switch radar/clock.
4.  Data sources: enable the ones you want. OpenSky needs a Client ID and Secret from opensky-network.org (API Clients). Flightradar24 needs a paid API subscription and a token.
5.  Weather: choose a provider under Sources → Weather provider settings. Open-Meteo and NOAA METAR need no key. OpenWeatherMap and WeatherStack need a free key.
6.  Backup: download the JSON configuration from the Device configuration page. The Wi-Fi password and API keys are not included.
