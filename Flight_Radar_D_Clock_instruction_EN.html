Flight Radar-D & Clock

Detailed manual: device, web interface and API key registration

A device based on ESP32-C3 with a round 240×240 screen. It shows nearby aircraft on a radar and works as a set of aviation-style clocks with weather. Everything is configured through a browser on a phone or computer.

Contents: Wi-Fi connection, radar, clocks and instruments, data sources, weather, API key registration, backups, troubleshooting. The firmware itself is not described in this manual.

1. What you need

  • The device with a USB power cable.
  • A home Wi-Fi network on 2.4 GHz. The device cannot see 5 GHz networks.
  • A phone or computer with a browser for setup.
  • For some data sources: accounts and keys (see section 9). Without them the radar and clocks still work, but some data may be unavailable.

2. Power on and Wi-Fi connection

2.1. First power-on without a home network

  1. Plug the device into a USB power source.
  2. If the home Wi-Fi is not set up or does not connect, the device creates its own access point RADAR.
  3. On your phone or computer, open the Wi-Fi list and connect to RADAR. The access point password is shown on the main settings page; by default it is 11223344.
  4. Open http://192.168.4.1 in a browser.
  5. Choose your home network from the list ("Scan networks") or type its name, enter the password and press "Save".
  6. The device restarts and connects to your home network.
If your system says the RADAR network has no internet access, choose to stay connected. The device does not need internet access to serve its settings pages on the local address.

2.2. Startup screen

SituationWhat the device shows
Home Wi-Fi is connectedThe text "YOUR NETWORK", the network name (SSID), the IP address and the web-interface address such as http://192.168.x.x. The screen stays for 10 seconds, then the radar or clock opens, depending on settings.
Home Wi-Fi is not connectedThe texts "HOME WI-FI NOT CONNECTED" / "CONNECT TO RADAR", the RADAR network name and the address HTTP://192.168.4.1. The screen stays for up to 5 minutes or until you press the button, then the device switches to the clock. The RADAR access point and the web server keep working.

The address on the home network can change after a router restart. The current address is always shown on the startup screen and at the top of the main page.

2.3. Emergency RADAR access point

If the home network is connected, the RADAR access point works for 10 minutes after startup and then turns off. This way it does not stay open to others. If there is no home network, the access point stays on until you connect to it or set up Wi-Fi.

The list contains 189 airports. 5. Radar: scales, aircraft, labels, search

5.1. Scales

Available scales: 6, 10, 20, 50, 100, 200, 400 and 1000 km. A short press of the button cycles through them. A scale you select with the button is saved as the default and restored after power-off.

On the Radar scales page you can mark which scales take part in button switching and set the display time for each scale in cycling mode.

5.2. How the radar looks

  • Centre — the chosen city or airport.
  • Aircraft — icons rotated to the heading. The icon type is chosen on the Data sources page: yellow aircraft silhouette or red triangle. Both have a purple heading line. Size: small, medium or large.
  • Selected aircraft — outlined with an orange dashed square. You can select it from the "Nearby aircraft" list.
  • Red dots at the edge — aircraft beyond the current scale. Press the button or choose a larger scale to see them.
  • Trails — the line the aircraft has flown. Enabled on the sources page; you can set the history length.
  • Map — borders, rivers and lakes under the radar. Enabled with its own switch.

5.3. Aircraft labels

On the sources page you can enable labels: callsign, altitude, speed, heading, distance from the centre and ICAO. Units are metric (km, km/h) or aviation (FL, kt, nm). The label font size is set in the "Labels next to aircraft" block: small, medium or large.

5.4. Automatic aircraft search

If automatic search is enabled and no aircraft is visible for the set time, the radar moves to the next scale and keeps searching up to 400 km. When an aircraft is found, the radar stays on that scale. Automatic search does not work together with cycling through scales.

5.5. Search by ICAO

If enabled, you can find a specific aircraft by its six-character ICAO code. If the aircraft enters the radar area, it is highlighted.

5.6. Auto-scale and random airport

Auto-scale by aircraft count. Set on the "Scales" page. If more aircraft are on screen than the "Maximum aircraft on screen" field allows (default 15), the scale decreases by one step. If there are no aircraft for one minute, the scale increases by one step, up to 400 km. There are 15 seconds between steps. While this is on, it replaces the auto-search from section 5.4. Untick it to turn it off: the auto-search then works again.

Random airport. Every set number of minutes (default 10), the radar centre and weather switch to a random airport from the list, and the scale becomes 50 km. This is temporary: the airport chosen on the main page does not change, and it is used again after a restart. The feature can be turned off on the same page. When the button pages through the radar scales, after the last scale an airport item appears: on the home airport it is "Random airport", on a random airport it is "Home airport". It is confirmed with a pause, like "AUTO". "Home airport" returns to the airport from the main page with the previous scale and stops random switching until the "Random airport" item is chosen or the device is restarted.

5.7. Tracking the selected aircraft

It is turned on by the checkbox on the Aircraft page (/aircraft) under the aircraft selection. While it is on and an aircraft is selected, the radar shows no other aircraft, labels or trails. If the selected aircraft leaves the screen, the scale increases in steps until it appears again. When it is gone completely at the 1000 km scale, tracking switches itself off. While tracking works, auto-search, auto-scale by aircraft count, the scale loop and the random airport do not change the scale or airport.

5.8. Transponder codes (squawk)

The device reads an aircraft's transponder code (squawk) from the data sources that provide it: OpenSky, adsb.fi, adsb.lol, adsb.one, airplanes.live and FR24. The code has four digits.

The codes 7500, 7600 and 7700 are shown on the radar as a filled red circle with the code written above it:

  • 7500 — hijacking (unlawful interference with the aircraft).
  • 7600 — radio communication failure.
  • 7700 — general emergency.

Other codes are not highlighted. If a source does not provide the code, no circle appears. Do not confuse this with the "Transponder" clock: there the time HHMM is shown as a code, not the aircraft's code.

6. Nearby aircraft

The "Nearby aircraft" page lists aircraft within the current radar range, sorted by distance. The list refreshes about every 10 seconds. For each aircraft you see the callsign, ICAO, data source, distance, altitude, speed, heading and vertical speed when the source provides them.

Press an aircraft to highlight it on the radar with an orange dashed outline. The highlight stays until you clear it or the aircraft leaves the radar area.

7. Data sources

The "Data sources" page controls where the aircraft data comes from and shows their status.

5.9. Default values

On first start, and after a settings reset, the device uses these values:

  • Radar centre and weather: Khrabrovo airport, Kaliningrad (KGD).
  • Radar scale: 200 km.
  • Random airport: off. You can turn it on on the scales page.
  • Aircraft sources: adsb.fi and adsb.lol enabled; OpenSky, airplanes.live, adsb.one and Flightradar24 disabled.
  • Weather: NOAA METAR for the selected airport.
  • Without internet, the clock opens in the artificial horizon style.

When you select another airport, the radar centre and METAR weather use it. Settings you have saved stay unchanged on the device.

5.10. Night screen mode

At night the screen turns off, and in the day it turns on again. On the Clock page turn on night mode separately for clock and radar: tick "Turn screen off at night in clock mode", "Turn screen off at night in radar mode", or both. The night and day start times are set there too, for example from 22:00 to 07:00. The time comes from synchronization (NTP or browser). Without time sync the screen stays on. The module backlight keeps shining, because this module does not allow dimming it.

At night a press of the BOOT button turns the screen on for 15 seconds, then it turns off again. This press does not change the clock style or the radar scale.

7.2. Source status

Source names are shown in different colours and status text is white. The colour only helps tell the services apart and does not mean the connection state.

7.3. Detailed diagnostics

The "Detailed source diagnostics" block refreshes every 5 seconds. For each enabled source it shows: time of the last successful response, time of the last attempt, number of aircraft received, freshest position age (if the source provides it), last HTTP code and error text. Disabled sources are not shown. If none is enabled, the block says so. Times count from power-on and reset on restart.

7.4. Map, trails, icon

  • Map under the radar — enabled with the "Map" switch.
  • Aircraft trails — enabled with the "Trails" switch; the default history is 120 seconds.
  • Aircraft icon — the "Aircraft marker" block: type (silhouette or triangle) and size.

8. Weather

Weather is used by the clock styles with weather (wind, METAR, weather station) and by the weather line on the screen. The settings are on the "Sources" page → "Weather provider settings".

ProviderKeyWhat to know
Open-MeteoNot neededWorks immediately. Temperature, humidity, precipitation, cloud cover, wind, pressure. Default choice.
OpenWeatherMapNeededUpdates every 15 minutes. Free plan, see section 9.
WeatherStackNeeded100 free requests per month, so updates happen every 8 hours.
NOAA METARNot neededWeather of the selected airport from METAR data. An airport from the list on the main page is needed, not arbitrary coordinates.

Setup:

  1. Open "Sources" → "Weather provider settings".
  2. In the "Use for clocks" field choose the provider.
  3. If the provider needs a key, paste it into the field. If a key is already saved, the field is empty — leave it empty to keep it.
  4. Choose units: temperature °C or °F, pressure hPa or mmHg.
  5. Press "Save". The new provider is requested at once.
If no weather appears, the "Weather for clocks" block on the sources page shows the reason: no Wi-Fi, no key, a provider error or a connection error.

9. Registration and API keys

Below are step-by-step instructions for services that need credentials. Site addresses and section names change over time, so if something differs, follow the service's official help. Do not send keys to third-party sites and do not publish them.

9.1. OpenSky Network (free, OAuth2)

  1. Open the official site opensky-network.org and sign up or log in.
  2. On your account page find the API Clients section and create a new API client.
  3. Download the issued file credentials.json. It contains the fields clientId and clientSecret.
  4. On the device open Data sources → OpenSky → "Upload credentials.json", choose the file and confirm.
  5. If you do not want to upload the file, type the Client ID manually and enter the Client Secret in the protected field on the sources page.
  6. Make sure the "Use OpenSky" checkbox is ticked and press "Save".
OpenSky uses OAuth2 Client Credentials. Your website login and password do not work for the device — you need the Client ID and Client Secret of the API client. Official authentication documentation: openskynetwork.github.io/opensky-api/rest.html

9.2. Flightradar24 API (paid)

This source needs a separate API subscription with API credits. A regular Flightradar24 website subscription does not give API access.
  1. Open the Flightradar24 API portal (fr24api.flightradar24.com), sign up or log in.
  2. Go to Subscription & credits and choose and activate an API plan.
  3. Open Key management and press Create token. Save the token somewhere safe immediately — the value may not be shown again.
  4. On the device open Data sources → Flightradar24, paste the token into the API token field and press "Save".

Documentation: fr24api.flightradar24.com/docs/getting-started and fr24api.flightradar24.com/docs/authentication

9.3. OpenWeatherMap (weather, free key)

  1. Open openweathermap.org and sign up.
  2. Confirm your email address: the message is sent to the address you entered.
  3. In your account open the API keys section and copy the key. The key may appear with a delay after registration.
  4. On the device open "Sources" → "Weather provider settings", choose OpenWeatherMap and paste the key. Press "Save".

As described in this manual, the free plan does not require a card, but terms can change — check them on the site before signing up.

9.4. WeatherStack (weather, free key)

  1. Open weatherstack.com and sign up for the free plan.
  2. Copy the Access Key from your account dashboard.
  3. On the device open "Weather provider settings", choose WeatherStack and paste the key. Press "Save".

The free plan is limited in requests per month, so the device updates the weather every 8 hours.

9.5. Sources without keys

No registration is needed for: Open-Meteo, NOAA METAR (aviationweather.gov), adsb.fi, airplanes.live, adsb.lol, adsb.one. Follow the limits and terms of each service.

9.6. Where keys are stored

  • Keys and tokens are stored in the device memory.
  • Keys are not included in the settings backup file. After restoring from a file, check them on the weather page and the sources page.
  • The OpenSky credentials.json file is secret. Do not publish it or send it to anyone.

10. Clocks and instruments

The "Clock settings" page selects the styles you can switch with the button and how long each one is shown. A single ticked style does not switch to another.

10.1. Instruments

  • Attitude indicator — sky and ground, bank scale, pitch marks. Smooth motion can be turned off.
  • Altimeter — drum-style altitude digits.
  • Gyrocompass — a compass card making one turn every 60 seconds. Rotation can be turned off.
  • Chronograph — cockpit clock with small dials.
  • ILS / glideslope — deviation needles for course and glide path. Motion can be turned off.
  • Transponder — time shown as a squawk code.
  • TERRAIN — terrain profile and the "terrain close" warning. Motion can be turned off.

10.2. Weather and station

  • Weather: wind — wind rose and direction arrow.
  • Weather: METAR — METAR-style string, temperature and QNH pressure.
  • Weather station — time, wind, temperature, humidity, precipitation, cloud cover, pressure.

10.3. Classic

  • Minimal — ring with seconds.
  • Radar — second hand.
  • Warm — warm colour scheme.
  • Night — dimmed colours.
Weather styles (wind, METAR, weather station) work only with Wi-Fi connected and a weather provider selected.

10.4. Automatic switching and simulation

You can set automatic style switching and the display time for each style. Smooth attitude motion and gyrocompass rotation can be enabled separately. Save the changes.

The settings also choose the mode after power-on: radar or clock.

11. Time and synchronization

The clock takes the time from the internet via NTP. The "Clock settings" page provides:

  • the "Sync with browser" button — sends the device the current time and time zone of the phone or computer that has the page open. It also works when you are connected directly to the RADAR access point;
  • a manual time zone relative to UTC;
  • the NTP server address, by default pool.ntp.org; the reset button brings back the default;
  • the time sync status.

After power-on the clock first shows a fallback time of 11:11, 1 January 2026 in the selected time zone. It runs like a normal clock until confirmed NTP time arrives or you press "Sync with browser". After that the date and time are corrected automatically.

If sync fails, check the home network connection and access to NTP servers. In RADAR access point mode without internet, NTP may be unavailable — use the "Sync with browser" button instead.

The "Network and IP address" page is at the bottom of the "Device configuration" page.

ModeWhen to use

13. Configuration: backup, restore, reset

The "Device configuration" page contains:

  • Save configuration — downloads a JSON file with the current settings.
  • Load configuration — choose a previously saved file. Current settings are replaced.
  • Reset settings — deletes the saved Wi-Fi, radar, clock and source settings. Only after confirmation.
  • Device information — version, memory, network status.
The backup file does not contain the Wi-Fi password, OpenSky Client ID and Client Secret, API tokens or weather keys. After restoring, enter or check them again. Keep the OpenSky credentials.json file separately.

14. Security

  • The default password of the RADAR access point (11223344) is publicly known. The access point is available only until the home network connects and for 10 minutes after startup if the network is connected, so do not leave the device with an open access point where strangers can connect.
  • Do not publish the Client Secret, tokens and API keys in public repositories, screenshots or messages. If a secret becomes public, revoke it on the service's website and create a new one.
  • Do not expose the device address to the internet: the settings pages are designed for the home network.
  • When moving the device, save the configuration and enter the keys again at the new place.

16. Quick start (English)

  1. Power the device via USB. If home Wi-Fi is unavailable, connect to the RADAR network (default password 11223344) and open http://192.168.4.1.
  2. Choose your home Wi-Fi network, enter its password and save. The device restarts and connects.
  3. Short press: next radar scale or next clock style. Hold about 3 seconds: switch radar/clock.
  4. Data sources: enable the ones you want. OpenSky needs a Client ID and Secret from opensky-network.org (API Clients). Flightradar24 needs a paid API subscription and a token.
  5. Weather: choose a provider under Sources → Weather provider settings. Open-Meteo and NOAA METAR need no key. OpenWeatherMap and WeatherStack need a free key.
  6. Backup: download the JSON configuration from the Device configuration page. The Wi-Fi password and API keys are not included.
